# Grade de Comando

Instalador da versão de teste do jogo. Para jogar, é preciso um convite.

Baixe o arquivo `Grade-de-Comando-Setup` em [Releases](../../releases/latest) e abra. O Windows pode mostrar um aviso de
aplicativo desconhecido: clique em "Mais informações" e depois em "Executar assim mesmo". O jogo se atualiza sozinho.
